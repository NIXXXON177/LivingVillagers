# LivingVillagers — Этап 0: окружение и заготовка проекта

Это стартовый каркас мода из ТЗ (`/home/user/villager-mod-tz/TZ_villager_mod.md`,
версия 4.1). Пока что мод **ничего не делает** в игре, кроме одной строчки в
логе — цель Этапа 0 только в том, чтобы убедиться, что окружение (JDK,
Gradle, Fabric, IntelliJ) настроено и проект собирается и запускается.
Волна 1 (жители с ролями) начнётся уже поверх этого каркаса.

## Что выбрано и почему (коротко)

- **Minecraft 1.21.1** — стабильная, долго актуальная версия с максимумом
  туториалов и готовых примеров на форумах/YouTube (важно для новичка).
- **Fabric Loader 0.16.9**, **Fabric API 0.116.6+1.21.1**, **Yarn-маппинги
  1.21.1+build.3** — последние версии, официально выпущенные именно под
  1.21.1.
- **Fabric Loom 1.12** (Gradle-плагин, который и умеет собирать Fabric-моды)
  — последняя версия Loom, которая ещё нормально работает на Gradle 8.x
  (более новые версии Loom требуют Gradle 9+ и более новую Java для самой
  сборки — не нужно на старте, лишний источник проблем для новичка).
- **Java 21** — обязательное требование Minecraft 1.20.5+.
- Раздельные `src/main` и `src/client` (`splitEnvironmentSourceSets`) — это
  подстраховка: код, который должен работать только у игрока (экран
  диалога, рендер), физически не может быть случайно вызван на сервере.

## Шаг 1. Установить Java 21 (JDK)

Проверь версию:

```
java -version
```

Если версия ниже 21 — нужно поставить JDK 21. Самый простой вариант: в
IntelliJ IDEA это можно сделать прямо из мастера импорта проекта (см. Шаг 3),
IntelliJ сам предложит скачать JDK нужной версии — отдельно ставить ничего
не обязательно.

Если хочешь поставить вручную — подойдёт любой дистрибутив: Eclipse
Temurin 21, Amazon Corretto 21 или Microsoft Build of OpenJDK 21.

## Шаг 2. Скачать/скопировать этот проект

Папка `livingvillagers/` (там, где лежит этот README) — это и есть весь
проект. Просто перенеси её целиком на свой компьютер (или клонируй из своего
git-репозитория, если ты уже настроил git).

## Шаг 3. Открыть проект в IntelliJ IDEA

1. `File → Open...` → выбери папку `livingvillagers` (не отдельный файл, а
   именно папку — там лежит `settings.gradle`, по нему IntelliJ поймёт, что
   это Gradle-проект).
2. IntelliJ спросит "Trust project?" — жми Trust.
3. Дальше IntelliJ сам найдёт `gradlew`/`gradlew.bat` и начнёт **импорт
   Gradle-проекта** — это и есть первая настоящая сборка: Gradle скачает сам
   Gradle нужной версии, потом Fabric Loom, потом сам Minecraft 1.21.1,
   Yarn-маппинги и декомпилирует/переименует классы игры в читаемые имена.
   **Это может занять от 5 до 20+ минут** в первый раз и требует интернета —
   это нормально, дальше кэшируется и повторные сборки быстрые.
4. Если IntelliJ спросит, какой JDK использовать для проекта — выбери 21-ю
   (или закажи её скачать прямо там же, кнопка "Download JDK").
5. Дождись, пока внизу справа (индикатор фона задач) закончится синхронизация
   Gradle и пропадут красные подчёркивания в `build.gradle`.

## Шаг 4. Запустить игру с модом (проверка Этапа 0)

В IntelliJ справа обычно появляется панель Gradle (значок слона). Там:

`livingvillagers → Tasks → fabric → runClient`

Дважды кликни по `runClient` — Gradle соберёт мод и запустит обычный
клиент Minecraft 1.21.1 с уже подключенным LivingVillagers. Первый запуск
тоже долгий (скачивание ассетов игры).

Альтернатива — через терминал из папки проекта:

```
./gradlew runClient        (Linux/macOS)
gradlew.bat runClient      (Windows)
```

**Как понять, что всё получилось:** после того как откроется окно
Minecraft (главное меню), открой лог — либо в консоли IntelliJ, либо в
файле `run/logs/latest.log` внутри проекта — и найди строку:

```
[main/INFO] (livingvillagers) LivingVillagers: мод загружен, окружение настроено верно (Этап 0 пройден).
```

Если она есть — Этап 0 пройден, окружение полностью рабочее, можно
переходить к Волне 1 (жители с ролями и расписанием, см. раздел 9 ТЗ).

## Структура проекта (что где лежит)

```
livingvillagers/
├─ build.gradle           — как собирать мод (версии, зависимости)
├─ gradle.properties      — версии Minecraft/Fabric в одном месте
├─ settings.gradle        — имя проекта
├─ src/main/java/com/livingvillagers/LivingVillagersMod.java   — общий код (сервер+клиент)
├─ src/client/java/com/livingvillagers/client/LivingVillagersModClient.java — только клиент
├─ src/main/resources/fabric.mod.json — "паспорт" мода для Fabric Loader
└─ src/main/resources/assets/livingvillagers/icon.png — иконка мода
```

## Частые проблемы

- **"Unsupported Java version"** — значит, что проект собирается не на
  JDK 21. Проверь `File → Project Structure → Project → SDK`.
- **Зависло на "Resolving artifacts"/скачивании** — проверь интернет,
  первая сборка тянет гигабайты (сам Minecraft, маппинги, Loom). Повторный
  запуск использует кэш и намного быстрее.
- **Красные подчёркивания в коде сразу после открытия** — это нормально,
  пока Gradle не закончил первую синхронизацию. Подожди её завершения.
